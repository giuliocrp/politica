# Politica Historical Record

This directory preserves source-grounded historical material for the completed
v1.0.0 and v2.0-prototype releases.

## Evidence hierarchy

1. Source code/data/tests at the relevant tag
2. Git history and tags
3. Committed project documentation
4. Claude Code completion reports
5. User-reported planning context

## Important rule

`POLITICA_V3_FACTUAL_BASELINE.md` is the factual input for V3 planning.
`POLITICA_HISTORY_GAPS_AND_CONFLICTS.md` records unresolved questions and must
be read alongside it.

The original `v2.0-prototype` tag is not moved by this documentation archive.
